Privacy Policy

Last updated: 19 November 2026

This policy explains how GTA6 Uploader ("the tool") handles data. The tool is used by one person, the owner of a single YouTube channel, on their own computer.

YouTube API Services

The tool uses YouTube API Services to upload videos to the owner's YouTube channel. By using the tool you agree to be bound by the YouTube Terms of Service. For how Google collects and uses data, see the Google Privacy Policy.

What data the tool accesses

  • Google account authorisation: the tool asks for the single scope https://www.googleapis.com/auth/youtube.upload, which only allows uploading videos to the signed-in user's channel.
  • Video files and metadata that the owner created: gameplay clips, titles, descriptions and tags.

The tool does not read, collect or analyse any other YouTube data. That includes other users' videos, comments, subscribers or analytics.

How the data is used

The data is used only to upload the owner's videos to the owner's channel. It is not sold, shared, used for advertising, or combined with other data.

Storage

The OAuth access token is stored only on the owner's computer, in a file readable only by the owner. Nothing is sent to any server other than Google's YouTube API. The tool has no database or cloud storage of its own, and it stores no data from other users.

Cookies and tracking

The tool sets no cookies and uses no analytics or tracking. This website uses no cookies or analytics either.

Revoking access and deleting data

  • You can revoke the tool's access to your Google account at any time at Google security settings (third-party access).
  • Deleting the local token file removes all stored authorisation data immediately.
  • Any stored API data is deleted within 30 days of revoking access, or sooner on request.

Contact

For questions about this policy, open an issue at github.com/vinaybothra/gta6-uploader/issues.

Changes

Any change to this policy will be posted on this page, with a new "Last updated" date.

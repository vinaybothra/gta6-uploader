# GTA6 Uploader – public pages

Static website with the homepage, Privacy Policy and Terms of Service for **GTA6 Uploader**. The tool itself lives in a separate private repo. These pages are required for the YouTube API Services audit.

- Live site: https://vinaybothra.github.io/gta6-uploader/
- Files: `index.html` (homepage), `privacy.html`, `terms.html`, `style.css`
- Hosting: GitHub Pages from the `main` branch root. No build step, no scripts, no tracking.
- Editing: change the HTML and push to `main`. Pages redeploys in about a minute.
